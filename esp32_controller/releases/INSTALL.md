# ESP32 Controller APK Install Guide

This folder contains a direct-install Android APK release.

## Files

- `esp32-controller-v1.0.0.apk`

## For Users (Android)

1. Download the APK file to your phone.
2. Open the APK from your Downloads app or file manager.
3. If Android blocks it, allow **Install unknown apps** for the app you used to open it (browser/file manager).
4. Continue install.
5. Optional but recommended: disable **Install unknown apps** again after install.

## Notes

- This APK is for direct distribution (not Play Store).
- If an older app is installed with a different signing key, uninstall that one first before installing this APK.
- Keep this file name format for future releases: `esp32-controller-vX.Y.Z.apk`.

# Guide d'installation APK ESP32 Controller (Francais)

Ce dossier contient une version APK Android a installation directe.

## Fichiers

- `esp32-controller-v1.0.0.apk`

## Pour les utilisateurs (Android)

1. Telechargez le fichier APK sur votre telephone.
2. Ouvrez l'APK depuis l'application Downloads ou votre gestionnaire de fichiers.
3. Si Android le bloque, autorisez **Install unknown apps** pour l'application utilisee pour ouvrir l'APK (navigateur/gestionnaire de fichiers).
4. Continuez l'installation.
5. Optionnel mais recommande: desactivez **Install unknown apps** apres l'installation.

## Notes

- Cet APK est prevu pour une distribution directe (pas Play Store).
- Si une ancienne version est installee avec une cle de signature differente, desinstallez-la avant d'installer cet APK.
- Conservez ce format de nom de fichier pour les prochaines versions: `esp32-controller-vX.Y.Z.apk`.
